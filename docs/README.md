# OpenSpot documentation

OpenSpot is currently a public-alpha research prototype. These documents describe what exists today and identify the work required for a reproducible release.

## Available guides

- [Networking](networking.md) — reference network topology and addressing.
- [Release roadmap](roadmap.md) — availability, known gaps, and release gates.
- [Hardware inventory](../hardware/README.md) — published mechanical artifacts and their maturity.

## Documentation conventions

- **Available** means the artifact is present in the repository.
- **Reference configuration** means it has been used by the project team but is not yet a frozen procurement or assembly specification.
- **Experimental** means it may change and has not completed the published validation criteria.
- **Planned** means it is not part of the current release.

Instructions must state their validation environment and date. Field observations should not be generalized into environmental, safety, reliability, or performance claims without a repeatable test procedure and results.
